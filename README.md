# Atelier Roblox – scripts

Bibliothèque des scripts du jeu Roblox de l'équipe.

Le fichier [`scripts.json`](scripts.json) est lu automatiquement par l'app Canva « Atelier Roblox ».

Chaque script contient :

| Champ         | Description                                            |
|---------------|--------------------------------------------------------|
| `id`          | identifiant unique                                     |
| `name`        | nom du script                                          |
| `project`     | projet / jeu concerné                                  |
| `category`    | `Gameplay`, `Interface`, `Systèmes` ou `Outils`        |
| `status`      | `À faire`, `En cours` ou `Terminé`                     |
| `author`      | auteur                                                 |
| `date`        | date d'ajout (AAAA-MM-JJ)                              |
| `description` | ce que fait le script                                  |
| `location`    | où le placer dans Roblox Studio                        |
| `language`    | `lua`                                                  |
| `code`        | le code complet                                        |
